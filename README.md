# Планировщик задач

## Описание проекта

Учебный проект — веб-приложение для планирования задач.

В приложении можно:

* создавать задачи;
* редактировать существующие;
* удалять задачи;
* отмечать задачи выполненными;
* создавать повторяющиеся задачи.

Данные сохраняются в SQLite. Для доступа к приложению дополнительно реализована авторизация по паролю через JWT.

---

## Выполненные задания со звёздочкой

В рамках дополнительной части проекта были реализованы:

* аутентификация через пароль и JWT-токен;
* проверка авторизации через middleware;
* сборка и запуск проекта через Docker.

---

## Запуск проекта локально

Перед запуском можно задать переменные окружения.

Пример для PowerShell:

```powershell
$env:TODO_PORT="7540"
$env:TODO_DBFILE="scheduler.db"
$env:TODO_PASSWORD="12345"
```

Запуск:

```bash
go run .
```

После запуска открыть в браузере:

```text
http://localhost:7540
```

Если указан `TODO_PASSWORD`, сначала откроется страница авторизации.

---

## Запуск тестов

Для проверки проекта:

```bash
go test ./tests
```

Для проверки авторизации необходимо указать значение `Token` в файле:

```text
tests/settings.go
```

Токен можно получить после входа через браузер из cookie `token`.

---

## Сборка и запуск через Docker

Сборка образа:

```bash
docker build -t scheduler .
```

Запуск контейнера:

```bash
docker run --name scheduler-app -p 7540:7540 -v ${PWD}/scheduler.db:/data/scheduler.db -e TODO_PASSWORD=12345 scheduler
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:7540
```
